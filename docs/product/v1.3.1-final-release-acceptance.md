# v1.3.1 补丁发布验收报告

## 1. 发布结论

验收日期：2026-08-23。

`v1.3.1` 达到当前单报告 ESG 披露分析产品闭环的本地发布标准，并作为 `v1.3` 之后的视觉一致性补丁基线。该补丁修复桌面侧边栏图片随主内容高度重新裁切的问题；业务 API、数据库、577 项 GRI 范围、规则结论、AI/人工分层、OCR、RAG、整改和导出语义均未改变。

`v1.3` 注释标签及 `docs/product/v1.3-final-release-acceptance.md` 保持不变，继续作为历史发布证据；`v1.3.1` 使用独立注释标签形成新的不可变交付点。

该结论属于本地产品与工程验收，不构成 GRI 认证、ESG 专家判断、外部鉴证、法律意见或企业生产部署承诺。

## 2. 补丁范围

| 项目 | 结果 | 边界 |
| --- | --- | --- |
| 侧边栏图片裁切 | 图片、遮罩和导航进入固定视口高度的 sticky 容器，不再随报告总览或完整核查的主内容高度变化 | 只修改共享前端布局 |
| 加载一致性 | 完整核查从加载状态切换到 577 项表格后，侧边栏图片不再重新裁切 | 不改变数据请求或表格行为 |
| 长页面导航 | 页面滚动到后续条款时，顶部栏和侧栏导航继续保持可见 | 导航结构和激活语义不变 |
| 版本契约 | 后端包、前端包和 OpenAPI 统一为 `1.3.1` | OpenAPI 路径和 schema 不变 |

六个报告工作区页面已完成桌面端浏览器对比：报告总览、完整核查、人工复核、整改任务、输出版本和审计时间线使用相同图片裁切。新增组件回归测试先失败、实现后通过，前端测试总数由 149 项增加为 150 项。

- 对外产品口径：577 项 GRI 核查。
- 内部结构：577 个标准单元、499 个独立判断项、78 个上下文项、0 个方法待确认项。

## 6. 已知限制

- 正式输入仍以数字文本型 PDF 为主；OCR 只有受控单页真实证据，通用扫描报告未达到生产能力标准。
- 外部模型默认关闭；DeepSeek 评估属于工程基线，不能替代 ESG 专家 gold。
- RAG Phase 1.5 继续作为离线影子诊断，不进入正式 evidence、assessment、risk、API、前端或导出。
- 第一版没有账号、权限、多租户、后台任务队列或企业级运维能力。
- 企业条件适用性仍可能需要企业确认。

## 7. 冻结与终止条件

`v1.3.1` 作为当前产品闭环发布基线冻结。本补丁完成后停止新增功能，后续只在真实使用证据满足已有条件化路线图时立项。

任何 GRI 清单、结构裁决、证据规则、risk-v2.1、模型/Prompt、数据库 schema、API 业务语义、三层权威关系或正式导出口径变更，都必须重新解冻并运行完整门禁。
