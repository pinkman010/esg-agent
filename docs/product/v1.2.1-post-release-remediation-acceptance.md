## 1. 结论

截至 2026-07-29，v1.2.1 发布后缺陷修复已完成代码、文档、完整自动门禁、Envision 冻结回归和 Chrome 产品回归。验收代码基线为 `61961ce`，正式发布标签 `v1.2` 继续指向 `876859f`，未移动、覆盖或重建。

## 9. 2026-08-17 中文展示边界补充验收

视觉迁移后的产品复验发现两项剩余展示泄漏：人工复核详情直接显示英文 GRI 要求正文；审计时间线直接显示完整 run/report/action 等内部 ID。只读诊断确认 Envision 当前 499/499 个独立判断项的 `effective_requirement_text` 均为纯英文，来源为官方英文标准资产；样例报告 6 条审计事件共包含 10 次内部标识值展示。

本次采用前端限定修复：

- 中文人工复核页保留 GRI 编号、中文判断依据、中文缺失项和证据；只有要求正文实际包含中文时才展示正文。英文标准原文继续保留在 API、数据库和标准 manifest，不做未经确认的批量翻译。
- 审计 API 和数据库继续保留完整关联 ID；产品时间线将运行显示为“分析运行记录”，隐藏内部 ID，并通过业务字段白名单阻止未知 payload key 回退到界面。负责人、截止日期、状态和适用性等已登记业务变更继续显示，可见错误或原因文本中的内部 ID 统一替换为脱敏提示。
- 输出文件下载及版本生成事件将四种内部格式枚举转换为产品名称，并将原始字节数转换为 B/KB/MB；PDF 页数及页面质量统计统一增加“页”单位，解析文本块数作为实现细节不进入产品时间线，文档解析状态使用中文说明。
- 后端代码、数据库 schema、GRI 结构、规则、证据、AI/RAG/OCR、人工快照和导出口径均未改变。
