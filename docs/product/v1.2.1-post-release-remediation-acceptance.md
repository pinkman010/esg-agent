# v1.2.1 发布后缺陷修复验收报告

## 1. 结论

截至 2026-07-29，v1.2.1 发布后缺陷修复已完成代码、文档、完整自动门禁、Envision 冻结回归和 Chrome 产品回归。验收代码基线为 `61961ce`，正式发布标签 `v1.2` 继续指向 `876859f`，未移动、覆盖或重建。

本补丁处理运行环境混用、旧服务未重启、复核人跨报告回填和主流程开发字段名暴露。规则、证据、risk-v2.1、GRI 结构、数据库 schema、导出语义、Prompt 和模型参数均未改变。

当前补丁仍是本地发布候选。尚未合并到 `main`，未创建 `v1.2.1` 标签，也未推送远端。

## 2. 修复范围

| 缺陷 | 根因 | 处理 | 验收结果 |
|---|---|---|---|
| 首页进入报告信息页后字段为空 | 普通产品服务连接长期回归库，最新 regeneration 技术记录没有产品 metadata | 普通产品统一使用 `APP_ENV=demo`、`esg_agent_demo` 和 demo runtime；health 返回安全环境身份 | Chrome 显示金风科技、2024 年、中文、52 页 |
| AI 授权说明暴露 `requirement`、证据 ID 等开发字段 | 产品文案直接使用内部代码术语 | 改为“核查项、证据编号、所在页码、规则结果、人工复核记录” | 组件真实渲染测试通过，目标技术文案静态扫描为 0 |
| 分析进度显示英文混合阶段名 | 阶段展示映射沿用内部术语 | 改为“GRI 核查项匹配” | Chrome 显示新文案，旧文案不可见 |
| 复核人默认显示自动验收名称 | `ReviewerGate` 从 localStorage 读取并跨报告写回 | 删除复核人持久化读写；每次进入仅使用本次页面 state | Chrome 输入框为空、按钮禁用；跨报告测试通过 |
| 完整范围显示英文表头和编号占位符 | 表头和搜索占位符未产品化 | 改为“GRI 核查项”和“核查项编号或条款内容” | Chrome 首屏 50 行，中文表头和占位符正确 |
| 报告审计记录加载失败 | 浏览器连接的旧后端没有当前 audit route，实际返回 404 | health 增加 `app_env`；404 `Not Found` 显示服务版本不一致；切换到当前后端 | OpenAPI 路由存在，接口 200，Chrome 显示 12 条事件 |
