# v1.3 最终发布验收报告

## 1. 发布结论

`v1.3` 达到当前单报告 ESG 披露分析产品闭环的本地发布标准。发布范围覆盖上传与报告信息确认、577 项 GRI 核查、证据追溯、规则结论、受控 AI 辅助、人工复核、整改、版本化输出、下载和报告级审计。

本版本冻结后停止继续叠加功能。后续工作转为真实产品使用、缺口收集和条件化迭代；缺少真实证据时，不启动通用 OCR、RAG Phase 2、后台队列、VLM 或企业级平台改造。

该结论属于本地产品与工程验收，不构成 GRI 认证、ESG 专家判断、外部鉴证、法律意见或企业生产部署承诺。

## 3. 产品闭环与数据口径

- 对外产品口径：577 项 GRI 核查。
- 内部结构：577 个标准单元、499 个独立判断项、78 个上下文项、0 个方法待确认项。
- 规则 assessment、AI suggestion 和人工 snapshot 分层保存；最终有效人工结论来自最新人工快照。
- 部分失败和 retry 通过 `parent_run_id` 运行谱系形成 577 项有效视图；失败或未生成项只展示分析状态和安全错误摘要，不伪造 verdict、证据、风险或人工结论。
- 数据库迁移代码 head、main 数据库和 demo 数据库均为 `0012_chunk_embeddings`。
- 资产清单共 49 项，缺失、哈希不一致和大小不一致均为 0。

- OCR capability、双重开关、页码边界、页数上限和稳定错误码已写入 `docs/product/api-contract.md`。

## 6. 已知限制

- 正式输入以数字文本型 PDF 为主；OCR 只有一页真实混合文本/图片报告证据，通用扫描报告仍未达到生产能力标准。
- 外部模型默认关闭；已有 DeepSeek 评估是工程基线，不能替代 ESG 专家 gold。
- RAG Phase 1.5 仍是离线影子诊断，不进入正式 evidence、assessment、risk、API、前端或导出。
- 第一版没有账号、权限、多租户、后台任务队列或企业级运维能力。
- 企业条件适用性仍可能需要企业确认。

## 7. 冻结与后续触发条件

`v1.3` 作为当前产品闭环发布基线冻结。后续只在真实使用证据满足对应条件时立项：

- 出现可复现的数字文本证据召回缺口，才评估 RAG Phase 2；
- 新增至少两类真实扫描报告和页级 gold，才评估通用 OCR、VLM 或后台队列；
- 出现持续运营、并发、权限或部署需求，才评估企业级平台能力；
- 获得独立 ESG 专家 gold，才扩展语义准确性评估。

任何 GRI 清单、结构裁决、证据规则、risk-v2.1、模型/Prompt、数据库 schema、API 业务语义、三层权威关系或正式导出口径变更，都必须重新解冻并运行完整门禁。
